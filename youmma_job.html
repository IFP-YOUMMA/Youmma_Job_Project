📱 YOUMMA-JOB

Plan de Développement Complet | Application Django MVP

🎯 Vue d'ensemble du projet

YOUMMA-JOB est une application web de mise en relation entre prestataires de services qualifiés et clients en République de Guinée. Ce document présente un plan de développement étape par étape, depuis la configuration initiale jusqu'au déploiement en production.

🐍

Backend

Django 5.x + PostgreSQL

🎨

Frontend

Tailwind CSS + Alpine.js

🚀

Déploiement

Nginx + Gunicorn + VPS

⏱️

Durée totale

6 semaines MVP

0
Configuration de l'environnement de développement
⏱️ 1-2 jours

0.1 Installation des prérequis système

Installer Python, PostgreSQL et les outils de développement nécessaires.
# Pour Ubuntu/Debian
sudo apt update sudo apt install python3.11 python3.11-venv python3-pip sudo apt install postgresql postgresql-contrib sudo apt install git curl
# Pour macOS (avec Homebrew)
brew install python@3.11 brew install postgresql@15 brew install git
💡 Note : Python 3.11+ est recommandé pour Django 5.x. PostgreSQL sera utilisé dès le développement pour éviter les divergences avec la production.

0.2 Configuration de PostgreSQL

Créer la base de données et l'utilisateur pour le projet.
# Se connecter à PostgreSQL
sudo -u postgres psql -- Créer la base de données et l'utilisateur CREATE DATABASE youmma_job_db; CREATE USER youmma_user WITH PASSWORD 'votre_mot_de_passe_securise'; ALTER ROLE youmma_user SET client_encoding TO 'utf8'; ALTER ROLE youmma_user SET default_transaction_isolation TO 'read committed'; ALTER ROLE youmma_user SET timezone TO 'UTC'; GRANT ALL PRIVILEGES ON DATABASE youmma_job_db TO youmma_user; \q
⚠️ Attention : Utilisez un mot de passe fort et conservez-le en sécurité. Ne le commitez jamais dans Git.

0.3 Création du dépôt Git

Initialiser Git et créer le fichier .gitignore pour le versioning.
# Créer le répertoire du projet
mkdir youmma-job cd youmma-job git init
✅ Bonne pratique : Créer un dépôt GitHub dès le début permet de versionner votre code et de le sauvegarder régulièrement.
1
Initialisation du projet Django
⏱️ 1 jour

1.1 Création de l'environnement virtuel

python3.11 -m venv venv\nsource venv/bin/activate

1.2 Installation Django et dépendances

pip install django==5.0 psycopg2-binary python-decouple Pillow djangorestframework

1.3 Création du projet

django-admin startproject youmma_job_project .

1.4 Configuration .env

Créer le fichier .env avec SECRET_KEY, DB_NAME, DB_USER, DB_PASSWORD

1.5 Premier test

python manage.py migrate\npython manage.py createsuperuser\npython manage.py runserver
2
Architecture et applications Django
⏱️ 1 jour

2.1 Création des apps

python manage.py startapp users\npython manage.py startapp profiles\npython manage.py startapp services\npython manage.py startapp reviews\npython manage.py startapp search

2.2 Enregistrement dans INSTALLED_APPS

Ajouter toutes les apps dans settings.py

2.3 Configuration templates

Créer templates/{base,users,profiles,services,reviews,search}
